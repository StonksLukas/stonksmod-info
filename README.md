# StonksMod - Info
Ein Discord Moderations-Bot der sehr starke und hoch entwickelte Systeme besitzt um dein Discord Server zu schützen! - 100% kostenfrei

# Module
AutoMod mit einer gut ausgebauten Datenbank (Große Listen an verbotenen Wörtern, Beleidigungen und bekannten Phishing/Scam links)
RaidRadar mit automatisiertem eingreifen (Temp Server Lockdown)
GhostPing Detector
Anti-Spam
Alt-Account schutz
KI-Schlichter (Analysiert den Chat und deeskaliert bei zu hohem Toxischen schreiben unter Usern)
Utilitys (Sonstige non-sicherheits Module wie Welcome-Message etc.)
